# Student Placement Analysis and Dashboard Using Power BI

## About the Project
This project analyzes student placement data using Microsoft Power BI. It helps visualize placement rates, company recruitment, and salary packages.

## Tools Used
- Power BI
- Microsoft Excel
- DAX

## Dataset
- Total Students: 6000
- Placed Students: 5000
- Not Placed Students: 2000
- Total Companies: 50
- Highest Package: 14 LPA
- Lowest Package: 3 LPA

## Dashboard Pages
1. Dashboard
2. Placement Analysis
3. Company Analysis
4. Salary Analysis

## Objective
To analyze student placements and present useful insights through interactive dashboards.

## Conclusion
This project helps understand student placement performance and salary trends using Power BI.
